# 수능·모의고사 유형별 풀이 전략

`solving.strategy`를 쓸 때 참고한다. 그대로 복사하지 말고 **이 지문에 맞춰** 구체적으로 바꿔 쓴다
(예: "주제문을 찾는다" → "4번 문장 However 뒤가 주제문이다"). 학생이 다음 문제에도 쓸 수 있는 순서여야 한다.

## 1. 18 목적 / 19 심경·분위기
**목적**
1. 글쓴이와 받는 사람의 관계를 확인한다(학교→학부모, 주민→관리소 등).
2. 앞부분은 배경·인사이므로 훑고, However / Unfortunately / I'd like to / Please / I'm writing to 뒤를 집중해서 읽는다.
3. 요청·거절·항의·안내 중 무엇인지 동사로 판단한다(ask, decline, complain, inform).
- 오답 함정: 글에 나온 소재(졸업식, 공연 등)를 섞은 선지. 소재만 같고 **행위**가 다르다.

**심경 변화**
1. 처음 심경: 앞 2~3문장의 형용사·행동(tears, heart pounding, smiled)을 표시한다.
2. 전환점 표지: But, Then, Suddenly, At that moment, 새 인물 등장.
3. 나중 심경: 마지막 2~3문장에서 확인한다.
4. 선지는 **앞 감정부터** 지워 나간다(두 번 확인하지 않아도 되는 경우가 많다).
- 심경 어휘 세트(긍정/부정, 긴장/안도)를 같이 정리해 주면 좋다.

## 2. 20 주장 / 21 함축의미 / 22 요지 / 23 주제 / 24 제목
**공통 순서**
1. 첫 1~2문장에서 화제(소재)를 잡는다.
2. 역접(However, But, Yet), 결론(Thus, Therefore, In short), 당위(should, must, need to, It is important) 표지 뒤 문장이 주제문 후보다.
3. 주제문 → 한국어 한 줄로 바꾼 뒤 선지와 대조한다.
- 주장: should/must가 있는 문장. 선지 '~해야 한다'와 대응.
- 요지: 주장보다 넓다. 연구·실험 글은 '결과'가 요지.
- 주제: 영어 선지 → 핵심 명사구(소재+관점)가 모두 있는지. 너무 넓거나(일반론) 너무 좁은(예시 하나) 선지를 지운다.
- 제목: 주제 + 비유·의문문 표현. 의문문 제목은 글이 답하는 질문인지 확인.
- 함축의미: 밑줄 표현의 **비유를 풀어** 앞뒤 문장 내용으로 바꿔 말한다. 밑줄 바로 앞뒤 문장에 근거가 있다.

## 3. 25 도표 / 26~28 내용 일치·불일치
- 도표: 선지의 수치 비교 표현(more than, twice, the lowest, the gap)을 표시하고 하나씩 계산한다. 배수·차이·순위 표현이 함정.
- 일치·불일치: 선지 순서 = 본문 순서. 선지 키워드(숫자, 고유명사)를 본문에서 찾아 대조. **불일치** 문제인지 발문부터 확인.
- 안내문: 날짜·요일·가격·대상·신청 방법·환불 조건 등 숫자와 조건(only, not, free, in advance)을 체크.

## 4. 29 어법 / 30 어휘
**어법 체크 순서**
1. 밑줄 앞뒤로 절의 구조(S+V)를 나눈다.
2. 자주 나오는 포인트: 수 일치(주어-동사 거리), 동사 vs 준동사, 능동 vs 수동/분사, 관계사 what/that/which vs 관계부사, 대명사 수·재귀, 형용사 vs 부사, 병렬, 도치, 조동사+have p.p.
3. 문장 구조를 먼저 보고, 문법명을 한 줄로 쓴다.
**어휘(문맥상 낱말)**
1. 글의 주제·흐름(+/-)을 먼저 잡는다.
2. 밑줄 낱말을 **반의어로 바꿔** 넣었을 때 더 자연스러운 것을 찾는다.
3. 정답 선지는 반의어 쌍(increase↔decrease, shorten↔prolong)으로 정리해 둔다.

## 5. 31~34 빈칸
1. 빈칸 문장을 먼저 읽고 무엇이 들어가야 하는지(명사/개념, 방향)를 정한다.
2. 빈칸이 주제문이면 주제를, 예시 문장이면 예시의 공통점을 찾는다.
3. 근거 문장 2~3개를 번호로 표시하고 **재진술(paraphrase)** 관계를 보인다(본문 표현 → 선지 표현).
4. 연결어(However, Thus, In other words)로 빈칸과 근거의 관계(같음/반대)를 확인한다.
5. 오답: 본문 단어를 그대로 쓴 선지, 반대 방향 선지, 너무 일반적인 선지.
- 이중부정·부정어(not, never, fail to, rather than)가 빈칸 문장에 있으면 방향을 거꾸로 생각해야 한다.

## 6. 35 무관한 문장 / 36~37 순서 / 38~39 문장 삽입
- 무관한 문장: 첫 문장(주제)과 같은 소재지만 **관점**이 다른 문장을 찾는다. 빼고 앞뒤가 이어지는지 확인.
- 순서: 주어진 글 마지막 문장 → (A)(B)(C) 첫 문장의 연결 단서를 본다. 지시어(this, these, such), 대명사, 연결어, 관사(a→the), 시간 순서.
- 문장 삽입: 주어진 문장의 단서(지시어, 연결어, 대명사)를 먼저 표시 → **논리가 끊기는 곳**(앞뒤가 갑자기 달라지는 곳)을 찾는다.

## 7. 40 요약문 / 41~42 장문 / 43~45 복합 장문
- 요약문: 요약문을 먼저 읽고 (A)(B)에 들어갈 의미를 예상 → 본문의 재진술 표현을 찾는다.
- 41~42: 제목(주제) + 어휘. 어휘는 30번과 같은 방법.
- 43~45: 순서(인물·시간·장소 이동), 지칭(she/he가 누구인지 표로 정리), 내용 일치.

## 8. 내신 변형 출제 체크리스트
지문마다 아래를 훑어 `naesin.points`, `grammar_checks`, `writing`에 반영한다.
- 주제문 → 주제·제목·요지 서술형, 요약문 완성
- 연결어 자리 → 연결어 문제 (However/Therefore/For example)
- 지시어·대명사 → 지칭, 문장 삽입, 순서
- 긴 수식어 뒤 주어-동사 수 일치, 관계사, 분사, to부정사/동명사 → 어법
- 반의어로 바꿀 수 있는 핵심 낱말 → 어휘 문제
- 정답 근거 문장 → 빈칸 변형(단어 → 구 → 절 빈칸)
- 핵심 구문(가주어-진주어, 강조, 도치, 분사구문, 동격) → 배열 영작, 조건 영작
- 등장한 연구·통계 수치 → 내용 일치
